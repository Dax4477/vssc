# VSSC Technician-B Electronic Mechanic Practice

Static single-page practice site with **260 questions**.

## Question bank
- 200 original high-chance VSSC-style practice questions
- 60 additional English-only questions adapted from the user-provided VSSC previous-year papers (2012, 2015, 2016, 2017, 2019, 2021, 2023)
- Hindi text and scan/OCR artefacts removed from the added PYQs
- Duplicate concepts were generally not re-added unless the previous paper tested a materially different angle

## Features
- Full 260-question practice mode
- Uploaded PYQ additions mode (60 questions)
- Topic filtering
- 80-question randomized mock exam
- 90-minute countdown
- +1 / -0.33 marking
- Explanations in practice/review mode
- Wrong-answer review
- Bookmarks
- Browser-local progress via localStorage
- No backend required

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` to the repository root.
3. Repository Settings -> Pages.
4. Deploy from branch -> `main` / root.
5. Save. GitHub will show the public Pages URL.

This is an independent study tool and is not affiliated with VSSC/ISRO.
