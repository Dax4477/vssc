# VSSC Technician-B Electronic Mechanic — Mastery Level Practice

Single-page GitHub Pages-ready practice site.

## Current format

- 260 questions
- 52 levels × 5 questions
- Perfect 5/5 required to unlock the next level
- 3 attempts on each active/requalification level
- After 3 failed attempts, that level is temporarily hidden
- Clear the previous level again with 5/5 to restore the hidden level
- Level 1 resets to three fresh tries if all three are used
- Question order and answer options reshuffle on every attempt
- Mastered levels can be reviewed without penalty
- Progress persists in browser localStorage
- Uploaded VSSC previous-year questions are presented in cleaned English only

## GitHub Pages

Upload `index.html` to the root of a repository and enable GitHub Pages for the repository branch. No server or database is required.
